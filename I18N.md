# 🌍 Internacionalización (i18n)

AutoCare soporta **Español** e **Inglés**.

## Estructura

```
lib/l10n/
├── app_es.json                    # Traducciones al Español
├── app_en.json                    # Traducciones al Inglés
├── app_localizations.dart         # Clase de localización
└── app_localizations_delegate.dart # Delegate de Flutter
```

## Uso

### En Widgets

```dart
import 'package:flutter/material.dart';
import '../l10n/app_localizations_delegate.dart';

class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final l10n = context.l10n;
    
    return Scaffold(
      appBar: AppBar(
        title: Text(l10n.vehiclesTitle),
      ),
      body: Text(l10n.vehiclesEmpty),
    );
  }
}
```

### Traducciones con Parámetros

```dart
// Archivos JSON
{
  "homeWelcome": "Bienvenido, {name}! 👋"
}

// En el código
final l10n = context.l10n;
Text(l10n.homeWelcome('Jorge'))  // Bienvenido, Jorge! 👋
```

## Idiomas Soportados

| Código | Idioma |
|--------|--------|
| `es` | Español |
| `en` | English |

## Cambiar Idioma en Tiempo de Ejecución

```dart
// Para cambiar el idioma, reinicia la app con la nueva locale
MaterialApp(
  locale: const Locale('en'),  // Cambiar a Inglés
  ...
)
```

## Agregar Nuevas Traducciones

### 1. Agregar a `app_es.json` y `app_en.json`

```json
{
  "newKey": "Nueva Traducción"
}
```

### 2. Agregar propiedad en `AppLocalizations`

```dart
String get newKey => translate('newKey');
```

### 3. Usar en widgets

```dart
Text(context.l10n.newKey)
```

## Traducciones Dinámicas

Para traducciones que cambian según parámetros:

```json
{
  "greetUser": "Hola {name}, tienes {count} vehículos"
}
```

```dart
// En el código
l10n.translate('greetUser', params: {
  'name': 'Jorge',
  'count': '5'
})
```

## Validación

Todas las cadenas hardcoded deben estar en los archivos JSON y referenciadas vía `context.l10n`:

```dart
// ❌ Incorrecto
Text('Iniciar Sesión')

// ✅ Correcto
Text(context.l10n.authSignIn)
```
